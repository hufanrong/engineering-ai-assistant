# 繁工AI 移动端 APP v1.2.0

繁工AI本地解析工作台的手机端APP，支持多电脑切换、离线缓存、自动同步。

## 新增功能（v1.2.0）

### 🖥️ 多电脑支持
- **添加多个电脑**：可以添加办公室电脑、项目部电脑等多个工作台地址
- **一键切换**：点击顶部标题栏或在网页中调用切换，快速在不同电脑间切换
- **电脑管理**：支持添加、删除、重命名电脑
- **自动记忆**：记住上次连接的电脑，下次打开自动连接

### 📦 离线缓存按电脑分组
- 每个电脑的离线缓存独立管理
- 切换电脑时只显示该电脑的待上传数量
- 连接到某电脑时只上传该电脑的缓存数据
- 删除电脑不影响其离线缓存数据

## 功能列表

- 📷 **拍照上传**：现场拍照直接上传到当前电脑
- 🎤 **语音上传**：现场语音记录自动转写上传
- 📝 **文字上传**：现场文字记录直接上传
- 📁 **文件上传**：选择手机中的文件上传
- 🏗️ **项目选择**：选择当前项目，资料自动归入对应项目
- 📊 **现场记录**：开箱检验、隐蔽工程、施工日志等快速生成
- 🤖 **AI助手**：手机端直接访问AI助手
- 📡 **离线缓存**：无网络时自动保存，联网后自动上传
- 🖥️ **多电脑切换**：支持多个电脑端，一键切换

## 编译打包步骤

### 方法一：Android Studio 编译（推荐）

1. 下载安装 [Android Studio](https://developer.android.com/studio)
2. 解压zip，Android Studio → Open → 选择 FanGongMobile 文件夹
3. 等待Gradle同步完成（首次约3-5分钟）
4. 菜单 Build → Build APK(s)
5. 编译完成点通知里的 "locate"，APK在 `app/build/outputs/apk/debug/app-debug.apk`
6. 传到手机安装

### 方法二：命令行编译

```bash
gradlew.bat assembleDebug  # Windows
./gradlew assembleDebug     # Mac/Linux
```

## 使用说明

### 首次使用
1. 电脑端启动工作台（`run_workbench.bat`）
2. 手机和电脑连同一WiFi
3. 电脑命令行 `ipconfig` 查看局域网IP
4. 打开APP，输入电脑名称和IP:端口 → 添加并连接

### 添加更多电脑
1. 点击APP顶部标题栏（显示当前电脑名称处）
2. 选择"添加新电脑"
3. 输入名称和IP:端口

### 切换电脑
1. 点击顶部标题栏
2. 从列表中选择要切换的电脑
3. APP自动加载该电脑的手机端页面

### 离线使用
1. 现场无WiFi时，正常拍照、语音、文字记录
2. 数据自动保存到手机本地，按电脑分组
3. 回到办公室连接WiFi后，APP自动检测并上传对应电脑的缓存数据
4. 顶部显示待上传数量，可点击"立即同步"手动触发
