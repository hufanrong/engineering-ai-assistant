# 繁工AI 移动端网页（独立版）

独立的手机端网页，可以部署到任何静态文件服务器，或直接在浏览器中打开。
通过配置电脑端工作台的API地址，实现手机端与电脑端的数据交互。

## 特点

- 📱 完全独立，不依赖电脑端的网页服务
- 🔗 可配置任意电脑端工作台的API地址
- 📷 支持拍照、语音、文字、文件上传
- 🏗️ 支持项目选择、现场记录、AI助手
- 📡 支持离线缓存（配合繁工AI APP使用）
- 🌐 可部署到云服务器，让手机在任何地方访问

## 使用方式

### 方式一：直接在浏览器打开
1. 将本文件夹复制到手机或电脑
2. 用浏览器打开 `index.html`
3. 首次打开会提示输入电脑端工作台的IP地址
4. 输入后即可使用

### 方式二：部署到静态文件服务器
1. 将本文件夹上传到任何静态文件服务器（如Nginx、Apache、GitHub Pages等）
2. 手机浏览器访问部署后的地址
3. 配置电脑端API地址即可使用

### 方式三：配合繁工AI APP使用
1. 繁工AI APP已内置本网页
2. APP启动后自动配置电脑端地址
3. 无需手动配置

## 配置电脑端地址

- 首次打开时会弹出配置对话框
- 输入电脑端工作台的IP:端口（如 `192.168.1.100:8756`）
- 配置保存在浏览器localStorage中
- 如需修改，清除浏览器数据或在控制台执行 `localStorage.removeItem('fangong_api_url')`

## 技术说明

- 纯HTML+CSS+JavaScript，无构建依赖
- 通过fetch API与电脑端工作台交互
- 自动将 `/api/*` 请求转发到配置的电脑端地址
- 响应式设计，适配手机屏幕
