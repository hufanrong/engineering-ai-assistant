# 口径决策书 · 2026-11-12

## 老板拍板（原文）

1. **「自动归类到已确定的车间，不确认留存让人工确认。」**
2. 台账验收口径（≥600 台 / ≥8 车间 / 位号≥90% / 熟料粉磨≥60 台）：**「认」**

## 两条硬规则

| | 规则 |
|---|---|
| **R1** | 只有**已确定的车间**才允许自动归类。已确定 = 设备台账来的 + 人工确认过的，**仅此两个来源** |
| **R2** | 匹配不上、拿不准的，一律推待确认队列**留存**，等人工签；**不许自动进正式车间清单** |

配套：**R3** 待确认必须有显眼入口（看不见等于没做）；**R4** 签一次就够，此后同类自动归类，不许问第二遍。

## 执行顺序（前提）

```
先导设备台账 → 用台账「子项名称」建白名单 → 自动归类文件 → 剩余推待确认
```

台账没进来，白名单为空，**所有文件都会变成待确认**。当前就是这个状态（24 台设备 / 2 个车间 / 候选 0），根因 D29。

## 对两个缺陷的直接约束

- **D27 必须改**：`from_ledger=false` 且未确认的名字（现为 `粗碎车间`）不得留在正式清单，降级待确认。判据：这类条目数必须为 **0**。
- **D29 提供白名单**：火法表 10 个 sheet 的「子项名称」（锂辉石库/烘干/计量、回转窑尾/中/头装置、熟料送存仓、熟料粉磨装置）就是 `from_ledger=true` 的白名单基底。

## 台账验收（四条同时满足）

| 指标 | 门槛 | 现状 |
|---|---|---|
| 设备总数 | ≥ 600 台 | 24 |
| 车间数 | ≥ 8 个 | 2 |
| 位号非空率 | ≥ 90% | 未达标 |
| 熟料粉磨单车间 | ≥ 60 台 | 0 |

任一不达标即判失败，不接受"部分通过"。

## 三处边界待裁定（我不擅自定）

| # | 情形 | 影响 |
|---|---|---|
| E1 | 一个文件命中多个已确定车间，取其一还是整份待确认 | 影响误归类风险 |
| **E2** | 台账自带的车间名要不要人工签一次 | **影响最大：决定导台账后要不要签 8~10 次** |
| E3 | 匹配是否放宽到"去后缀后相同" | 放宽会重新引入"猜名字" |
