# 手机端对接云库说明（v0.1.14）

手机端 App（免登录）只需配置云库地址，即可：
- **户外读取**：在线检索云库（多台电脑合并后的完整项目资料）；
- **现场上传**：拍照/语音/文字直接传回云库"现场区"，回办公室后电脑端一键拉取并解析入库。

## 一、云库地址

```
http://<服务器IP>:8760
```

服务器 IP 在部署云库的电脑上 `ipconfig` 查看（如 `192.168.1.50`）。手机与服务器同一局域网可直接用；跨网需在路由器放行 8760 端口。

## 二、手机端读取（在线检索）

```
POST http://<服务器IP>:8760/api/cloud/search
Body: { "query": "P-101 离心泵 安装位置", "top_k": 5 }
返回: { "results": [ { "file_name": ..., "text": "规范/台账/解析正文...", "score": ... } ] }
```

前端示例（WebView / H5）：

```js
async function cloudSearch(query) {
  const r = await fetch(`http://${SERVER}/api/cloud/search`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ query, top_k: 5 })
  });
  return (await r.json()).results || [];
}
```

## 三、手机端现场上传（照片/语音/文字）

免登录，只写上传人姓名；同一手机记住姓名后不再询问。

**① 传照片 / 语音文件**（multipart）：

```
POST http://<服务器IP>:8760/api/cloud/field-upload
Form:  project=紫金XX项目  上传人=张三  kind=photo|voice  note=设备开箱照片
       file=@/本地图片.jpg
```

**② 纯文字现场记录**（语音转文字 / 手输施工记录）：

```
POST http://<服务器IP>:8760/api/cloud/field-upload
Form:  project=紫金XX项目  上传人=张三  kind=text  note=今日浇筑完成，强度报告后补
```

返回 `{ ok:true, status:"added"|"duplicate", uploader:"张三" }` —— `duplicate` 表示同一张照片重复上传已自动跳过（按内容 SHA256 去重）。

## 四、电脑端拉取解析（工作台⑨云库页）

1. 电脑端工作台打开 **⑨ 云库** 页；
2. 点 **"拉取现场资料并解析"**：自动把云端现场照片/语音/文字全部下载到本地，并按原有解析引擎（OCR 铭牌/语音转文字/文本分类）自动解析入库、进上传队列；
3. 解析结果进入项目库后，⑧资料生成计划、⑤关联图谱、③AI 检索自动可用。

## 五、完整闭环

```
手机端（户外）                      云端服务器               电脑端（办公室）
拍照/录音/文字 ──field-upload──▶ 现场区 ──pull-field──▶ 自动解析入库
手机端检索 ◀──cloud/search──── 完整云库 ◀──payload上传── 各电脑解析结果
```

## 六、鉴权（可选）

云库 `app.py` 顶部 `API_KEY` 默认为空（仅内网）。上公网前必须改强密码，手机端调用时加请求头：

```
Authorization: Bearer <API_KEY>
```

## 手机端 AI 助手（v0.1.19）

手机端不用本地装大模型，通过云库桥接电脑工作台的 AI 助手：

```
POST http://<云库服务器IP>:8760/api/cloud/ai-chat
Authorization: Bearer fanGong_cloud_2026
Content-Type: application/json

{ "query": "生成 1号车间 P-101 吊装方案，设备重3.5t", "history": [] }
```

返回（桥接到工作台时）：
- `mode: local_doc` + `doc.content_b64`（base64 的 Word，可下载保存为 .docx）
- `mode: local_rag` + `answer`（本地多库检索回答，含命中文件/规范/工程结构）
- `mode: gateway`（工作台配置了 AI 网关时的联网问答）

前置：云库服务器 `cloud_server/app.py` 顶部配置
`AI_WORKBENCH_ENDPOINT = "http://<电脑工作台IP>:8756"`（工作台需已启动，且在云端服务器上可达）。
未配置时自动降级为云库本地检索（返回相关文件清单）。
