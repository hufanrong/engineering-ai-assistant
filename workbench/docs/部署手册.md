# 繁工AI · 本地解析工作台 —— 部署手册（v0.1.19 版）

> 适用版本：v0.1.19 及之后（手机端 AI 助手桥接已就绪）。
> 覆盖：电脑端工作台部署、云端合并主库部署、AI 网关配置、手机端对接、多电脑并库、平台规范核验配置。

---

## 一、系统组成

```
┌─────────────────────────────────────────────────────────────┐
│  手机端 App（现场拍照/语音/文字/选项目）                        │
│     │  field-upload（免登录，只写上传人姓名）                  │
│     ▼                                                       │
│  云库 cloud_server（端口 8760，公网/公司服务器）              │
│     │  ai-chat 桥接（可选）                                   │
│     ▼                                                       │
│  电脑工作台（端口 8756，本地解析引擎）                        │
│    ├─ 项目库：扫描/上传 → 解析 → 向量化 → 车间归类 → 关系图谱  │
│    ├─ 平台库：规范上传 → 联网自动核验（6个月） → 正文引用       │
│    ├─ 资料计划 → 一键生成 Word（施工/吊装方案等 10 类）        │
│    └─ AI 助手：多库检索 + 资料生成（可接 AI 网关联网问答）     │
└─────────────────────────────────────────────────────────────┘
```

## 二、电脑端工作台部署（第一次部署约 15 分钟）

### 2.1 环境要求

- Windows 10/11（或 Linux/macOS）
- Python 3.10 ~ 3.12（安装时勾选 **Add python.exe to PATH**）
- 磁盘：建议 ≥ 50GB（图纸/照片多）；内存 ≥ 8GB（CAD 解析建议 16GB）

### 2.2 一键安装（推荐）

1. 解压 `繁工AI_本地解析工作台_vX.Y.Z.zip` 到任意目录（如 `D:\fanGongAI\`）
2. 双击 `install-full.bat`（自动创建虚拟环境并安装全部依赖：fastapi、python-docx、ezdxf、paddleocr 等；需联网，约 5~10 分钟）
3. 双击 `run_workbench.bat` 启动
4. 浏览器打开 `http://127.0.0.1:8756` 即可使用

> 也可手动部署：
> ```
> python -m venv venv
> venv\Scripts\activate
> pip install -r requirements.txt
> python start.py
> ```

### 2.3 首次使用流程

1. **平台库**（⑦页）：先上传常用规范（GB/T、JGJ 等 txt/pdf/word）。上传时自动联网核验：
   - 现行 → 立即标注"现行"
   - 废止 → 标注"已废止，最新版：GB/T XXXX-2026，请上传替换"
   - 无法核验 → "待核验"（人工在状态列改为"现行/废止"）
   - 每 6 个月自动到期核验（⑦页"检查过期"按钮可手动触发）
2. **项目库**（①~⑤页）：
   - "扫描/上传"页选文件夹（或拖入文件/粘贴文件夹路径自动上传）
   - 自动解析（CAD 图纸 / 表格台账 / 图片 OCR / PDF / Word / Project XML）
   - 自动识别车间并归类（图纸与台账冲突时人工确认，设计院编号优先）
   - 关联图谱自动建立：设备 ↔ 图纸 ↔ 台账 ↔ 铭牌照片
3. **资料计划**（⑧页）：看每类工程资料缺什么 → 点"去生成" → 弹窗补字段 → 一键 Word
4. **AI 助手**（⑩页）：直接问；含模板名即生成资料文档

## 三、云端合并主库部署（端口 8760）

目的：多台电脑各自解析，云端并为一个完整库；手机在户外也可用。

### 3.1 服务器/公司主机

```bash
cd cloud_server
pip install -r requirements.txt
# 双击 run_server.bat，或：
python app.py          # http://0.0.0.0:8760
```

### 3.2 工作台连接云端

编辑 `app/config.py`：

```python
CLOUD_ENDPOINT = "http://<服务器IP>:8760"     # 公司内网用内网 IP，公网用公网 IP/域名
CLOUD_API_KEY  = "fanGong_cloud_2026"         # 与 cloud_server/app.py 的 API_KEY 一致
NODE_NAME      = "我的电脑"                    # 本机节点名（云库按节点区分来源）
```

工作台⑨云库页：连接状态 → 一键"上传解析结果到云端"（自动 SHA256 去重）→ "拉取现场资料并解析"（手机上传的照片/语音/文字拉到本机解析）。

### 3.3 多电脑并库（两种方式）

- **在线并库**：每台电脑配置同一个 CLOUD_ENDPOINT，各自"上传解析结果"，云库自动合并去重
- **离线并库**：电脑 A ⑨页"导出 .fglib"→ 拷贝 → 电脑 B 导入（⑦平台库同样支持 .fpglib 导出导入）

### 3.4 手机端 AI 助手桥接

`cloud_server/app.py` 顶部：

```python
AI_WORKBENCH_ENDPOINT = "http://<电脑工作台IP>:8756"   # 手机 → 云库 → 工作台 AI
```

未配置时云库自动降级为轻量检索回答。

## 四、AI 网关配置（联网问答，可选）

工作台本地默认 `AI_MODE = "local"`：知识类提问返回本地多库检索结果，资料生成离线可用。
若你有一个 AI 网关/豆包工作伙伴端点（可联网搜索），配置后升级为完整 AI 问答：

编辑 `app/config.py`：

```python
AI_MODE = "gateway"
AI_GATEWAY_ENDPOINT = "http://<你的AI网关>/chat"      # POST {"query","context","history"} → {"answer"}
AI_GATEWAY_API_KEY  = ""                              # 如需鉴权
```

AI 助手会自动把本地检索到的项目库/平台库/工程关系/资料待办作为 `context` 注入网关，回答基于你的解析库 + 联网知识。

## 五、手机端对接

手机端不需要登录，上传只需写上传人姓名（同一手机记住姓名，不再询问）。

- **现场上传**：`POST /api/cloud/field-upload`（multipart：project / uploader / file，支持照片/语音/文字/视频）
- **现场清单**：`GET /api/cloud/field-list`
- **AI 对话**：`POST /api/cloud/ai-chat`（见上，桥接工作台）
- **检索云库**：`POST /api/cloud/search`

完整示例见 `docs/手机端对接云库.md`。

## 六、平台规范核验配置（可选，增强自动核验）

`app/config.py`：

```python
PLATFORM_SEARCH_ENDPOINT = ""      # 自定义核验服务：POST {"std_no"} → {"status":"现行|废止","latest_no":...}
STD_VERIFY_OPENSTD = True          # 内置：全国标准信息公共服务平台尽力而为核验
STD_VERIFY_ON_UPLOAD = True        # 首次上传即核验
```

不配置自定义端点时，工作台用内置 openstd 通道（公司电脑可达性更佳）；仍无法核验的进"待核验"人工处理。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 启动报 `ModuleNotFoundError` | 重新 `pip install -r requirements.txt`（或 install-full.bat） |
| CAD 解析失败 | 确认已装 ezdxf：`pip install ezdxf`；DXF 版本过高可用另存为低版本 |
| 图片 OCR 不识别 | 确认 paddleocr/paddlepaddle 已装；手机照片需拍清铭牌/图纸 |
| 8756/8760 端口被占用 | `ss -tlnp \| grep 8756` 查占用进程；或改 config 端口 |
| 手机连不上云库 | 服务器防火墙放行 8760；公网需端口映射/域名 |
| 云端 AI 不可用 | 检查 AI_WORKBENCH_ENDPOINT 指向的工作台是否启动、IP 是否可达 |
| 规范一直"待核验" | 服务器网络限制 openstd；配置自定义 PLATFORM_SEARCH_ENDPOINT 或人工改状态 |

## 八、数据备份与迁移

- 项目库 + 关系图谱：`data/` 目录整个拷贝（含 vectordb 向量库）
- 平台库：`platform_data/` 目录，或⑦页"导出 .fpglib"（新电脑"导入"即用，无需重新上传规范）
- 云端库：`cloud_server/cloud_data/` 目录
- 新电脑部署后：先导入 .fglib/.fpglib，再同步 data/ 即可继续工作
