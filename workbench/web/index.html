工程资料生成（施工方案 / 吊装方案 / 交底 / 验收记录）

选择方案类型 → 自动从解析库预填车间设备 → 填写关键数据（缺项会提示）→ 生成 Word 下载，人工打印签字。规范依据内置，可人工补充。

平台级规范库（国标/规范/通用文件，独立于子项目库）

规范/标准在此单独建库，所有项目共享；AI 检索项目库时可同时读取平台库（引用规范正文内容而非名称）。上传时立即登记有效期，每 6 个月自动提醒核验；配置联网端点后可自动搜索最新版替换。新电脑安装时导出 .fpglib 导入即可复用。

工程资料生成计划（按项目进度，缺项进待办）

系统根据解析库自动判断"库里已有什么、每类资料缺什么"。缺的部分列出清单，把资料补进库后该资料自动转为"可生成"；也可在下方人工登记资料任务（现场进度需要做什么就登记什么）。生成结果优先 Word，签字由人工下载打印。

云库（多电脑合并 + 手机端现场上传）

云库把多台电脑的解析结果合并为一个完整库，手机端配置云库地址即可户外读取；手机端上传的现场照片/语音/文字会先到云端"现场区"，点"拉取现场资料"即可自动下载并解析进本地项目库。连接配置在 app/config.py 的 CLOUD_ENDPOINT / CLOUD_API_KEY。
